## 基石技术现状归纳

| 基石技术 | 现状与趋势 |
|---|---|
| **Transformer** | 无可争议的统一骨架，语言/视觉/动作/世界模型全部 token 化。唯一实质挑战来自 Mamba/SSM（线性复杂度，端侧推理友好），目前是补充而非替代 |
| **LLM + RLHF** | 语义大脑已就位；瓶颈从"会不会推理"转向"推理结果是否符合物理"。π*0.6 代表新方向：VLA 直接从真机经验做 RL |
| **CLIP** | 图文对齐的"通用货币"：PVR、语义 SLAM、语言抓取全部以它为底座；正被 DINOv2（像素级）和 SigLIP 分走场景 |
| **扩散模型 → 流匹配** | 图像生成与动作生成共用同一数学引擎；π0 用流匹配把推理提速数倍，是当前动作头的主流选择 |
| **Decision Transformer** | 打开了"RL 即序列建模"的门，RT/Gato/世界模型全是它的后裔 |
| **VLA（RT-2 → π0）** | 具身智能的当前主线。开源生态成型（OpenVLA 7B + LoRA），趋势是双系统（快慢脑）+ 世界模型融合 + 真机 RL |
| **Diffusion Policy / ACT** | 实验室标配基线：多模态动作分布（扩散）与时序一致性（分块），绝大多数后续工作在其上改造 |
| **3D Gaussian Splatting** | 图形学与 AI 的交汇点：SLAM、场景重建、语言抓取都在用它取代 NeRF；与图形学背景最对口 |
| **Dreamer / Genie** | Dreamer 证明"想象中学习"可行；Genie 把世界模型做成"可交互基础模型"，是通往数据自生成的关键 |
| **OXE / ARIO 数据** | 领域真正瓶颈：数据规模化比模型创新更卡脖子；ARIO（300 万轨迹、五模态）是最新基础设施 |
| **Isaac / Genesis 仿真器** | NVIDIA Isaac（工业标准、GPU 并行）与 Genesis（2024 开源新锐、可微物理）是 Sim2Real 主战场 |

## 近期学习计划（6 周）

> 目标：从黑盒到看懂自己的 LeRobot ACT 训练日志。
> 投入：每周 8-10 小时业余时间。

### 阶段 1　深度学习基础　[打底]（第 1-2 周）

- 搞懂：`loss`、反向传播、梯度下降、过拟合
- 视频：3Blue1Brown 神经网络系列（4 集，全看）
- 视频：Karpathy「Zero to Hero」— 仅前 3 讲（micrograd / makemore 基础）
- 书：《动手学深度学习》d2l.ai（中文版）— 前 4 章，其余按需查阅
- 验收：能手画反向传播计算图；说清 lr 过大/过小时 loss 曲线长什么样

### 阶段 2　PyTorch 实战　[工具]（第 3 周）

- 搞懂：`tensor`、`Dataset/DataLoader`、`nn.Module`、训练循环
- 教程：PyTorch 官方 60 分钟入门
- 书：d2l.ai 的 PyTorch 实现章节（边看边跑）
- 验收：不查资料，30 分钟内手写一个 MNIST 训练循环并跑通

### 阶段 3　模仿学习 & Transformer（ACT 的核心）　[领域]（第 4-5 周前半）

- 搞懂：行为克隆、`l1_loss + kld_loss`、动作分块、CVAE
- 论文：ACT: Action Chunking with Transformers — 精读正文 + 附录消融表
- 视频：Karpathy「Let's build GPT」
- 教程：LeRobot 官方 ACT tutorial
- 验收：能回答 ACT 为什么用 CVAE（多模态动作分布）、kl 权重的作用、动作分块为何抗抖动

### 阶段 3.5　Diffusion Policy 对照　[对照]（第 5 周后半，2-3 天）

- 搞懂：扩散模型直觉（加噪 → 迭代去噪）、动作生成为何适合多模态分布
- 三点对照：
  1. 生成方式：ACT 用 CVAE 隐变量采样 vs DP 用迭代去噪
  2. 多模态性：都为解决"同一观测多种正确动作"，路径不同
  3. 速度 vs 上限：ACT 单次前向（快） vs DP 多步去噪（慢但分布更灵活）
- 资源：Diffusion Policy 项目页 + 论文摘要/图1/图2；LeRobot 仓库 `policies/diffusion/` 与 `policies/act/` 并排对照读
- 验收：能一句话说清两者取舍

### 阶段 4　回看自己的训练日志　[目标]（第 6 周）

- 读懂日志字段：
  - `loss` 总损失（主体是 l1）
  - `l1_loss` 动作预测误差
  - `kld_loss` CVAE 隐变量正则（ACT 中通常乘 kl_weight≈10，贡献很小，正常）
  - `grdn` 梯度范数（偏大时关注梯度裁剪）
  - `lr` 学习率；`mem_gb` 显存占用
- 源码：`lerobot/policies/act/modeling_act.py` — 对照 ACT 前向与 loss
- 文档：LeRobot 官方 tutorials — 数据格式与评估指标
- 验收：能判断自己训练是否健康
