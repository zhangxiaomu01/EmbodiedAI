# 具身智能技术栈调研

梳理具身智能领域主流技术栈：以 NVIDIA 全家桶为主线，逐层介绍各组件的定位与解决的问题，并对标其它普遍采用的替代方案。

## 一、NVIDIA 全栈概览

NVIDIA 提供了覆盖"数据 → 训练 → 验证 → 部署"的完整具身智能管线：

```
真实示教数据(少量)
        ↓
Cosmos 扩展生成海量合成数据 ←── Isaac Sim 也产出仿真数据
        ↓
GR00T 基础模型 + 混合数据后训练
        ↓
Isaac Sim/Lab 仿真中验证策略
        ↓
部署真机 → 采集新数据 → 回到起点
```

一句话分工：**Isaac 提供环境，Cosmos 制造数据，GR00T 消费数据成为模型。**

### 1.1 Isaac —— 仿真与开发平台（"练武场"）

- **Isaac Sim**：基于 Omniverse 的通用机器人仿真器，提供逼真物理 + 渲染、传感器模型（LiDAR/相机/IMU）、ROS 接口，有完整 GUI
- **Isaac Lab**：构建在 Isaac Sim 之上的强化学习训练框架，针对 RL 做大规模并行化（GPU 上同时跑数千个仿真环境）
- **Isaac ROS**：真实机器人的感知/导航软件栈，基于 ROS 2 的常用模块（视觉 SLAM、检测、规划）的 GPU 加速版本

**解决的问题**：真机数据采集和训练又慢、又贵、又危险、难复现。先在仿真里大规模训练/验证，再 Sim2Real 部署。

**Isaac Sim vs Isaac Lab**：

| | Isaac Sim | Isaac Lab |
|---|---|---|
| 定位 | 通用仿真平台 | 强化学习训练框架 |
| 关注点 | 场景搭建、传感器仿真、渲染、数字孪生 | 大规模并行 RL 训练 |
| 形态 | 完整应用（有 GUI） | Sim 之上的 Python 库 |
| 典型用途 | 验证感知算法、生成数据、Sim2Real 测试 | 训 locomotion/manipulation 策略，数千环境并行 rollout |

简单记：Sim = 仿真器，Lab = 用仿真器训 RL 的工具箱。

### 1.2 Cosmos —— 世界基础模型 + 合成数据（"数据工厂"）

- 一组预训练的 **World Foundation Models (WFM)**：扩散/自回归视频生成模型，输入文本、视频或传感器数据，生成物理合理的视频场景
- 配套 tokenizer、数据策展管线（curation）、后训练工具
- 是"世界模型"（World Model）概念的大规模实现：通过海量视频预训练学会物理规律，能预测/生成世界如何演化

**解决的问题**：真实世界数据不够用、长尾场景采集不到（撞车、掉落、罕见工况）。典型用法：少量真机数据 → Cosmos 扩展出成千上万条变体（换光照、材质、视角、干扰物）。

**与 GR00T 的分工**：Cosmos 生成的是视频/数据（给训练用），GR00T 生成的是动作（给执行用）。

### 1.3 GR00T —— 人形机器人基础模型（"大脑"）

- **GR00T N1/N2**：开源的 VLA（Vision-Language-Action）基础模型，双系统架构——VLM 负责推理（System 2）+ 扩散策略生成连续高频动作（System 1）
- 提供后训练（post-training）和部署管线，少量真机示教数据即可微调出可用操作技能

**解决的问题**：机器人缺一个能"看图听指令直接输出动作"的通用模型；提供预训练基座，避免从零训练。

**与 RT-2 的关系**：同一技术路线（VLA）上的同类产品，非继承关系。

- **RT-2**（Google DeepMind, 2023）：VLA 路线开创者之一，将 VLM 微调输出离散化动作 token，闭源
- **GR00T**（NVIDIA, 2025）：开源权重，输出连续动作（扩散头），配套 NVIDIA 自家数据管线（Cosmos 造数据、Isaac 验证）

### 1.4 Omniverse / PhysX —— 底座

- **Omniverse**：NVIDIA 的 3D 协作与仿真平台，核心组件：
  - **USD（Universal Scene Description）**：皮克斯开源的场景描述格式，不同 3D 工具场景互通
  - **PhysX**：GPU 加速物理引擎，刚体/软体/流体/布料动力学，支持 GPU 大规模并行物理计算
  - **RTX 渲染**：光线追踪照片级渲染，仿真视觉数据接近真实摄像头
- Isaac Sim = Omniverse + 机器人模块（URDF 导入、传感器模型、ROS 接口）
- 关键价值：**GPU 全栈加速**（物理计算 + 渲染都在 GPU），单环境每秒可仿真很多步，支撑 Isaac Lab 的数千环境并行 RL 训练——传统 CPU 仿真器做不到这个规模

## 二、逐层替代方案对比

### 2.1 物理仿真器（对标 Isaac Sim）

| 方案 | 特点 |
|---|---|
| **MuJoCo** | 学术界最流行，接触动力学精确，DeepMind 收购后开源免费；CPU 为主，MJX 支持 GPU 并行 |
| **Genesis** | 2024 年底开源的新星，生成式物理引擎，速度号称比 Isaac 快 10-80 倍，全 GPU |
| **PyBullet** | 免费轻量易上手，精度和速度一般，教学/原型用 |
| **Gazebo** | ROS 生态官方仿真器，传统机器人领域标配，慢但生态深 |
| **CoppeliaSim** | 工业界常用，场景搭建方便 |
| **SAPIEN / ManiSkill** | 清华系，面向操作任务（manipulation）的仿真 + 基准 |
| **Webots / Drake** | Webots 教学友好；Drake 适合控制理论研究 |

### 2.2 大规模 RL 训练框架（对标 Isaac Lab）

| 方案 | 底层仿真器 / 生态 |
|---|---|
| **MJX (MuJoCo XLA)** | MuJoCo，JAX 生态，GPU/TPU 并行 |
| **Brax** | Google 自研可微物理引擎，TPU 友好 |
| **ManiSkill 3** | SAPIEN，GPU 并行操作任务训练 |
| **Gymnasium + Stable Baselines3** | 通用 RL 入门标配（非机器人专用） |
| **skrl / rl_games / RSL-RL** | 各类 RL 算法库；RSL-RL 是 ETH 四足机器人方案（legged_gym 系） |

### 2.3 VLA / 机器人基础模型（对标 GR00T）

| 模型 | 机构 | 特点 |
|---|---|---|
| **π0 / π0.5** | Physical Intelligence | 当前公认最强开源 VLA 之一，扩散动作头 |
| **OpenVLA** | Stanford 等 | 7B 开源 VLA，学术界复现基准 |
| **RT-2 / RT-X** | Google DeepMind | 闭源，VLA 路线开创者 |
| **Octo** | UC Berkeley 等 | 开源通用策略，Transformer 架构 |
| **RDT-1B** | 清华 | 双臂操作扩散基础模型 |
| **RoboFlamingo 系** | 各学术组 | 基于 LLaVA 类 VLM 改造 |

### 2.4 数据生成 / 世界模型（对标 Cosmos）

此层 NVIDIA 目前最领先，对标者较弱：

| 方案 | 说明 |
|---|---|
| **Genie 2 / 3** | DeepMind 可交互世界模型，偏游戏/通用场景 |
| **Sora / Veo** | OpenAI/Google 视频生成，非机器人专用，被用于数据增广研究 |
| **RoboGen / GenSim / DexMimicGen** | 学术界程序化任务生成 + 示教数据自动合成管线 |
| **MimicGen** | NVIDIA 自家前作（少量人类示教→自动扩展），非生成模型路线 |
| **域随机化** | 各家普遍做法：domain randomization，不用世界模型 |

### 2.5 数据格式与开源数据生态（对标 NVIDIA 数据管线）

| 方案 | 机构 / 说明 |
|---|---|
| **LeRobot** | Hugging Face，开源社区事实标准：数据格式 + 训练框架 + 模型 hub，SO-100 等低成本机械臂生态 |
| **Open X-Embodiment + RLDS** | Google DeepMind 牵头的跨机器人数据集联盟与数据格式 |
| **DROID** | Stanford 等，大规模真实世界操作数据集 |
| **ARIO** | 国内统一数据格式尝试（All Robots in One） |

### 2.6 中间件（对标 Isaac ROS）

**ROS 2 没有对手**——机器人领域事实标准中间件（节点间话题/服务/动作通信，统一传感器、控制器、算法模块的"对话"方式；相比 ROS 1 改进了实时性、多机支持、DDS 通信、生产可用性）。NVIDIA 自己的 Isaac ROS 也是基于 ROS 2。非 ROS 路线只有：DDS 裸用、LCM（MIT 四足）、厂商私有协议。

## 三、典型组合方案

| 场景 | 组合 |
|---|---|
| **学术复现路线** | MuJoCo/ManiSkill + LeRobot + OpenVLA/π0 + RLDS 格式 |
| **国内公司常见** | Isaac（仿真绕不开）+ 自研 VLA + 自采真机数据 + ROS 2 |
| **低成本开源社区** | LeRobot + SO-100 机械臂 + π0/OpenVLA 微调 |

## 四、竞争格局总结

- **仿真层**：Isaac 几乎垄断，Genesis 是最有力的挑战者
- **模型层**：GR00T 只是众多 VLA 之一且未必最强，π0 更常被对标
- **数据管线层**：Cosmos 独家领先，暂无真正对手
- **生态层**：Hugging Face 的 LeRobot 是最大对手

整体链路串联：**Omniverse/PhysX 是底座，Isaac Sim 在底座上搭机器人场景，Isaac Lab 用场景并行训策略，Cosmos 用世界模型造数据补真实数据不足，GR00T 吃数据变成能干活的大脑，ROS 2 是这一切与真实机器人之间的通用语言。**
